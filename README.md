# ECON 122 spot-check

A one-page tool for drawing a random student during the in-class activity.

It holds **no data**. The roster and every recorded draw live in a private
repository the page talks to via the GitHub API, using a fine-grained token you
paste once per browser. Without that token this page does nothing but show a
setup form.

Published at <https://mgelman.github.io/econ122-spotcheck/>.
